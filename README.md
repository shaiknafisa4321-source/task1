# Design Choices:

I kept the design simple and personal:

- A diagonal gradient background that fades from soft lavender-blue to light blush pink
- A white card with rounded corners and a gentle shadow, so the text stands out
- An indigo heading as the one bold pop of color
- Soft grays for body text, which are easier on the eyes than pure black
